# Нейро-аналитик конкурентов

Исследовательский проект Елены Горлановой: воспроизводимый сбор публичной базы конкурентов, сравнение промптов и моделей, интерфейс для проверки фактов с цитатами.

**[Открыть интерфейс базы](https://gorlanova-automation.github.io/competitor-neuro-analyst/)**

## Текущий результат

- Подробный пилот: Immigration Relocator и Migrun. Согласовано 8 конкурентов, полный сбор ещё не выполнен.
- 175 черновых фактов последнего опыта, 3 карантинные записи, 25 публикаций публичного Telegram-превью.
- 16 строк источников двух снимков: 15 успешных и 1 robots_disallowed_or_unavailable.
- 5 реальных модельных опытов; одинаковые контрольные тексты проверены по сохранённым запросам.
- Luna v3 нашла 8/8 заранее размеченных цен португальских страниц. Полная смысловая точность 175 фактов ещё не проверена.
- 17 проверок кода и отрицательные проверки подмены источника/запроса прошли.

## Что делает интерфейс

Показывает снимок собранной базы: факты, источники, эксперименты, публикации и карантин. Есть поиск, фильтры компании/страны/типа факта, карточки с точными цитатами и экспорт текущей выборки в CSV. Просмотр работает статически, без API-ключей и новых запросов к моделям. Изменение человеческих отметок и новый сбор из интерфейса пока не реализованы.

Python получает и очищает исходники. LLM извлекает значения. Python проверяет структуру, цитаты и числа. Человек подтверждает смысл и сопоставимость. Успешная проверка цитаты не доказывает истинность рекламного заявления компании.

## Локальный просмотр

```sh
python -m http.server 8765 --directory docs
```

Открыть `http://localhost:8765/`. Статические файлы также можно открыть напрямую через `docs/index.html`.

Для обновления публичного снимка из данных репозитория: `python prepare_public.py`. После клонирования репозиторий уже содержит все необходимые для просмотра данные. Установка зависимостей нужна только для коллектора: `pip install -r stage_2/code/requirements.txt`.

## Проверки и воспроизведение исследований

```sh
python -m unittest discover -s stage_2/code -p 'test_*.py'
python stage_2/code/research_audit.py stage_2
```

Тарифные оценки вычисляются из сохранённого usage и опубликованных базовых ставок на 22.10.2026. Это не фактическое списание ProxyAPI. Время в реестре относится к опыту целиком; индивидуальная задержка API не журналировалась. v3 меняет одновременно промпт и валидатор, поэтому влияние факторов отдельно не измерено.

## Остаток работ

Полная смысловая проверка, расширение эталона за пределы цен, сбор Испании и всех восьми конкурентов, поисковая выдача, проверка соцсетей/карт и рекомендации. Отсутствие факта в неполном корпусе не означает отсутствие услуги у компании.

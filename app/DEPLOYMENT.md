# Серверное рабочее пространство

Адрес: https://neuroanalyst.fghk.ru/

Приложение размещено отдельным Docker-контейнером на существующем VPS владельца. Старые сервисы не заменяются. HTTPS обслуживает существующий Caddy; настроен отдельный виртуальный хост `neuroanalyst.fghk.ru`. Приложение обслуживается от корня своего домена; клиент использует API того же адреса. Прежние маршруты нейроаналитика удалены из конфигурации `youtube.fghk.ru`, который принадлежит другому приложению.

## Пользовательский сценарий

1. Войти по паролю рабочего пространства.
2. Указать сайт. Сервер получает страницу и готовит редактируемый профиль с помощью ИИ.
3. Подтвердить профиль. Сервер выполняет поиск и проверяет кандидатов на соответствие задаче клиента.
4. Подтвердить список. Известную компанию можно добавить вручную, в том числе найти её сайт по названию.
5. Нажать «Начать анализ». Одно фоновое задание собирает сайты и публичные Telegram-публикации, строит ИИ-профили, отдельно оценивает преимущества своей компании, сравнивает предложения и проверяет рекомендации. Более широкий несопоставимый ассортимент не считается превосходством над специализацией. Изменения ради заполнения плана не предлагаются.
6. Читать результат в приложении. История и результаты сохраняются на сервере; JSON — необязательная экспортная копия.

## Эксплуатация

Отдельный постоянный каталог `/opt/neuroanalyst/data` монтируется как `/data`. Непривилегированный процесс UID 10001. Контейнер имеет лимит 1 CPU / 1 ГБ RAM и автоматический перезапуск. Порт приложения доступен на loopback и в сети обратного прокси. Секреты находятся вне Git, в файле окружения с правами 0600.

Обязательные переменные: `ANALYST_PASSWORD`, `ANALYST_ALLOWED_HOSTS`, `PROXYAPI_KEY`. Поиск: `ANALYST_SEARCH_ENABLED=1`, `ANALYST_SEARCH_PROVIDER=tavily`, `TAVILY_API_KEY`. Счётчик поискового лимита находится в постоянном томе; автоматического платного пополнения нет. Модель — `openai/gpt-6-luna`, без автоматических повторов модельных вызовов. Публичные материалы передаются модели для анализа; ключи остаются на сервере.

Вход через форму устанавливает подписанную cookie на 12 часов (HttpOnly, SameSite Strict, Secure при HTTPS). Есть выход и ограничение попыток входа. Basic Auth сохранён для служебных проверок API. Защита кабинета обязательна: это единое пространство владельца, а не многопользовательский SaaS. Аккаунты клиентов, изоляция арендаторов, подписки, биллинг, резервное копирование вне VPS и восстановление заданий после аварии требуют отдельного этапа. При перезапуске незавершённое задание помечается прерванным; собранные материалы сохраняются.

Telegram проверяется по ссылкам сайтов и публичной поисковой выдаче t.me. Автоматическая принадлежность требует обратной ссылки на сайт и совпадения бренда. Сомнительный канал не становится официальным автоматически. Поиск внутри Telegram-клиента и визуальный анализ изображений в этот запуск не входят; интерфейс показывает эти ограничения.

Colab остаётся исследовательским и демонстрационным инструментом. GitHub Pages не исполняет Python и направляет новые исследования в серверное приложение.

При подготовке модельного ввода страницам сайта резервируется 70% текстового бюджета, если есть публикации Telegram. Длинная повторяющаяся навигация не должна вытеснять основное содержание: используются непрерывные фрагменты исходного текста, общий каталог сохраняется отдельным фрагментом. Все цитаты остаются привязаны к исходному URL и хешу. Кэш профиля переиспользуется только при совпадении входного корпуса; изменённый корпус требует нового профиля. На компанию приходится до одного модельного запроса; далее до одного на оценку преимуществ, одного на сравнение и одного на проверку рекомендаций.

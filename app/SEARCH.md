# Поиск конкурентов

Выбор от 08.11.2026: Tavily, бесплатный пилот без оплаты и пополнения.
Официальные условия: https://docs.tavily.com/documentation/api-credits
Контракт: https://docs.tavily.com/documentation/api-reference/endpoint/search

На сервере нужны ANALYST_SEARCH_ENABLED=1, ANALYST_SEARCH_PROVIDER=tavily и
TAVILY_API_KEY в секрете окружения. Ключ нельзя добавлять в Pages, GitHub,
публичные ноутбуки, JSON результатов или чат.

Один запуск делает один basic-запрос (1 кредит), максимум 10 кандидатов.
Автоматических повторов, переходов на другого провайдера и обхода CAPTCHA нет.
ANALYST_SEARCH_MONTHLY_LIMIT=1000 ограничивает попытки этого приложения;
неудачные попытки также учитываются консервативно. Это не баланс аккаунта:
расходы других приложений сюда не входят. Платный тариф и PAYG не подключать.
Счётчик ANALYST_SEARCH_BUDGET_FILE должен быть на постоянном диске
(в Docker /data/search_budget.json). Запускать один процесс Uvicorn:
блокировка счётчика действует между потоками, не между процессами.
Повреждённый или недоступный счётчик останавливает поиск до запроса API.

Проверяются HTTP-ошибки, таймауты, JSON и размер ответа (до 2 МБ).
URL нормализуются, собственный домен, дубликаты и приватные адреса исключаются.
Каждый кандидат требует проверки человеком; поиск не подтверждает релевантность.

Ручное продолжение: открыть обычную выдачу в браузере, при необходимости
самостоятельно пройти CAPTCHA, вставить названия и HTTPS-адреса в приложение,
исправить список и подтвердить. Такие записи отмечаются как добавленные
пользователем, а не найденные API. Браузерные cookies серверу не передаются.

В сохранённой попытке DuckDuckGo получен HTTP 202 с заданием выбрать уток,
status=challenge_page; SHA-256 страницы:
0f2aa383537e8bd1473517d9e6422e64b06b209b6d027d31f2f25e1903517328.
Точную причину антибот-проверки по этому ответу определить нельзя.
08.11 обычный браузер показал выдачу без CAPTCHA; это не прохождение прежней проверки.
Старый HTML-поиск доступен только при явном ANALYST_SEARCH_PROVIDER=duckduckgo.

Brave рассматривался как альтернатива, но требует карту для активации:
https://api-dashboard.search.brave.com/documentation/quickstart
Tavily выбран для пилота без карты; сравнительная полнота выдачи пока не измерена.

Здесь открыта публичная витрина

Собранная база доступна по ссылке слева. Для нового сбора запустите приложение на компьютере или финальный Colab: GitHub Pages хранит страницы, но не исполняет Python.

python -m pip install -r stage_3/code/requirements.txt -r app/requirements.txt
python -m app

Затем откройте локальное приложение. Ключ API для базового сбора не нужен.

1. Сайт своей компании

Если страница не загружается — предоставить текст

Вставьте скопированный текст публичной страницы. В отчёте он будет отмечен как предоставленный пользователем.

2. Проверьте профиль

Черновик составлен по метаданным страницы. Исправьте описание и укажите рынок.

3. Подтвердите конкурентов

Можно запустить поиск кандидатов или указать известных конкурентов. Добавленные вами адреса сохранят эту отметку.

4. Собрать данные и подготовить отчёт

Приложение собирает доступные публичные страницы. Недоступные источники попадут в отчёт с причиной. Ссылки на соцсети не считаются прочитанными публикациями.

Предоставить текст недоступной страницы конкурента

Смысловой анализ модели запускается отдельно в финальном Colab. Ключ хранится в секрете Colab.

Цитаты позволяют проверить происхождение наблюдений. Автоматические текстовые сигналы требуют смысловой проверки; визуал и эффективность продвижения оцениваются отдельно.

# Этап 2. Нейро-аналитик конкурентов

Пилот: Immigration Relocator, Португалия и Испания, русскоязычные граждане СНГ. Сравниваются комплексный переезд и отдельные юридические услуги. Профиль и восемь конкурентов подтверждены пользователем 21.10.2026.

## Кто что делает

1. Человек подтверждает профиль, список компаний, принадлежность спорных аккаунтов и контрольные примеры.
2. Python загружает HTML публичных страниц, сохраняет байты, URL, время UTC, HTTP-статус и SHA256; очищает текст BeautifulSoup, обнаруживает ссылки, разбивает текст на фрагменты.
3. Языковая модель через ProxyAPI извлекает факты из этих фрагментов. API вызывается Python, но семантическое извлечение выполняет LLM.
4. Python проверяет схему, существование источника и точного подтверждающего фрагмента, помещает сомнительные записи в карантин, сохраняет JSON/CSV и очередь проверки.
5. Человек проверяет смысл и сопоставимость фактов. Совпадение цитаты само по себе не доказывает верность интерпретации.

Ручные находки прежних сообщений — подготовка, а не автоматический результат. Наличие кода не означает, что все источники уже собраны. Фактическое выполнение определяется журналами запусков.

## Структура

- `code/`: модуль, ноутбук Colab, настройки, промпты, схема и проверки.
- `runs/`: отдельная папка каждого запуска, исходный HTML, очищенный текст, источники, факты, ошибки и эксперименты.
- `review/`: ручная контрольная выборка и результаты сравнения.
- `docs/`: связь с курсом, методика, отчёт и ограничения.
- `company_profile_draft.json`, `competitor_candidates.json`: подготовка и согласованный состав.

## Соцсети, карты и выдача

Ссылки обнаруживаются на сайтах. Публичная веб-лента Telegram может получаться Python без входа. Instagram/Facebook/LinkedIn часто требуют входа и JS: HTTP 200 не доказывает доступ к публикациям. Поиск внутри соцсетей и просмотр карт/первой страницы Google и Яндекса фиксируются отдельными событиями с запросом, языком, регионом, способом получения и источником. Незавершённые действия остаются в очереди, а не считаются выполненными. Предлагаемая выборка — 90 календарных дней включительно по дате запуска, до 20 последних публикаций на площадку; количество доступных публикаций и минимальная/максимальная даты сохраняются отдельно. Нельзя обходить CAPTCHA или ограничения входа.

## ProxyAPI

Секрет читается только внутри Colab: `google.colab.userdata.get('PROXYAPI_KEY')`. Endpoint и модель задаются настройками; список моделей загружается с `/v1/models`. Ключ не печатается, не включается в конфигурацию, запросы на диске, ответы тестов или архив. Источники документации: https://proxyapi.ru/docs/models , https://proxyapi.ru/docs/text-generation , https://proxyapi.ru/docs/structured-outputs (проверены 21.10.2026).

## Запуск

Открыть ноутбук в своём Google-аккаунте, предоставить ноутбуку доступ к существующему секрету, выполнить ячейки сверху вниз. По умолчанию выбраны только Immigration Relocator и Migrun. Расширение до всех девяти — после проверки пилотного результата. Каждая функция получает пути, настройки и данные через параметры.

Текущий проверенный вариант извлечения: atomic_coverage_v3 (отдельный файл prompt_next_experiment.json), реальный опыт20261022T113037Z_be7ea6. Его запуск включается отдельно RUN_NEXT_PROMPT; два исходных промпта сохранены для воспроизводимости истории.15 офлайн-проверок. Реальные ответы и расходы см. research/experiment_cards.md и runs/20261022T111451Z_0f8116/experiment_audit.json. Смысловая проверка полного набора и поисковая выдача остаются открытыми.

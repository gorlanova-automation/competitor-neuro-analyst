# Основания в материалах курса

Прочитаны исходные ячейки семи ноутбуков без исполнения учебного кода и без использования сохранённых outputs. Каталог курса: `Разработчик AI агентов` по адресу из memory.md. Нумерация ячеек ниже с нуля.

| Раздел и ноутбук | Проверенный пример | Применение и дополнение в дипломе |
|---|---|---|
| 17, «Функции УИИ», «Модули УИИ» | Функции с аргументами, импорт; «Модули», ячейки 103, 108, 111–112 — создание .py, open/with | Отдельный модуль, параметры вместо скрытых результатов предыдущих ячеек, запись файлов |
| 19, «Библиотека Pandas I УИИ» | Ячейки 20–31 — CSV и encoding, 106–108 — сохранение локально/на Drive | Табличная база CSV; в минимальном модуле стандартный csv вместо обязательной зависимости Pandas; display DataFrame в Colab |
| 21, «Нейро-консультант на базе GPT с диалогом УИИ» | Ячейка 21 — userdata.get; 22, 25 — вызов модели, роли system/user и message.content | Colab Secrets PROXYAPI_KEY, тот же принцип system/user; HTTP-запрос к совместимому API ProxyAPI, схема и журнал добавлены для диплома |
| 22, «Нейро-консультант дообученный на базе знаний УИИ.ipyn.ipynb» | Ячейка 33 — HTTP-загрузка с raise_for_status; 36, 41 — чанки и metadata | Сбор текста, фрагменты с URL/идентификатором/смещениями; в первой версии собственный простой splitter без FAISS |
| 23, «Ноутбук1 Создание баз знаний УИИ» | Текстовые объяснения подготовки и разбиения материалов, включая заключение в ячейке 14 | Подготовленный корпус, сохранение метаданных; векторный поиск пока не нужен для извлечения по всем фрагментам |
| 27, «Материал Асинхронное_программирование» | Ячейки 47, 49, 55 — requests/aiohttp, BeautifulSoup, CSS-селекторы, urljoin, обработка HTTP-ошибок | requests + BeautifulSoup + urljoin. Сначала последовательный ограниченный обход, чтобы видеть ошибки; массовая асинхронность отложена до проверки |

Схема фактов, проверка цитат, SHA256, robots.txt, журнал происхождения, очередь проверки соцсетей и оценка качества — разработка для диплома, а не дословно готовая программа курса. Случайная смена User-Agent из учебного примера не переносится: используется один понятный User-Agent. Старые примеры модельных имён курса не считаются актуальным каталогом ProxyAPI.

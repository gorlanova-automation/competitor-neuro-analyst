## Реально выполнено

Python сохранил исходные HTML, очищенные тексты, URL, время, хэши и фрагменты. Локальный первый корпус содержит 8 страниц и22 фрагмента; новый независимый Colab-корпус — runs/20261022T111451Z_0f8116. Из публичного Telegram-превью получены25 публикаций двух каналов; полнота не доказана, принадлежность требует проверки. Страницы и заявления компаний не являются независимым подтверждением эффективности их услуг.

Первый шаг реализован отдельно: сайт → профиль с точными цитатами → ручные поправки и подтверждение → план поисковых запросов. Пробный вызов Luna вернул25 элементов профиля после проверки цитат и10 в карантине. Новый профиль остаётся черновиком. Восемь запросов по двум странам построены на ранее согласованном ручном профиле. Исполнение поисковой выдачи и автоматический отбор новых конкурентов пока не подключены.

В учебном Colab через PROXYAPI_KEY выполнены реальные запросы. Ключ не записан в код, файлы или отчёт. Каталог подтвердил наличие openai/gpt-6-luna. Сравнивались два исходных промпта на Luna, затем один evidence_v2 на Luna/Gemini/Claude. Все ответы, usage, отказы валидатора и промпты сохранены.

Это совпадения по правилам на восьми заранее размеченных ценах, не полная точность базы. Стоимости — оценки по сохранённым токенам и тарифному снимку ProxyAPI, не фактический счёт. Для v3 усилен валидатор, поэтому изменение числа принятых фактов нельзя приписать только промпту.

Gemini помещала суммы в поле service вместо отдельного price. Ответ Claude по IR обрезался на4096 токенах; второй ответ получен. Для следующего сравнения нужны адаптация контракта и явные поддерживаемые лимиты вывода. Нельзя делать общий вывод о качестве вендоров по этим настройкам.

В v2 выявлены неполные доказательства: короткая цитата заголовка сопровождала перечисление четырёх виз; отдельные geography/service терялись. В v3 этот конкретный пример исправлен: типы виз вынесены отдельно с полными цитатами, все8 контрольных цен сохранены, представлены все9 типов полей. Три карантинные записи сохранены; две цены NIF/самозанятости требуют проверки цитат, ставка аренды не содержит нормализованной суммы. Полная смысловая разметка175 фактов ещё не выполнена.

Доработан Python: карантин цитат только с суммой, проверка противоречия валюты, хэши кода/корпуса будущих опытов, повтор на сохранённом корпусе, промежуточное сохранение benchmark, учёт токенов неполных ответов.15 офлайн-проверок прошли. Тест валюты добавлен после v3; исторический запуск не переписывался.

## Выбор моделей

Luna — предварительный рабочий выбор для текущего извлечения: прошла контроль цен при меньшем расчётном расходе. v3 исправляет наблюдавшиеся дефекты, но дороже v2 и ещё требует смысловой проверки. Для профиля и запросов есть проба Luna, сравнения альтернатив пока нет. Для итоговых рекомендаций окончательная модель не выбрана. Обоснования по этапам и тарифы — docs/model_selection.md.

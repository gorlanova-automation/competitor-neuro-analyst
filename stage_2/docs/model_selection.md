# Выбор моделей по этапам

Обновлено 22.10.2026. Документ объединяет результаты пилота и план проверок для остальных этапов.

Стартовая модель пилота — `openai/gpt-6-luna`. Точный идентификатор найден в каталоге ProxyAPI и официальной документации OpenAI. Доступ конкретного ключа проверяется через /v1/models перед экспериментом.

## Протокол выбора

Сначала сравнить два промпта на Luna при одинаковом корпусе. Затем зафиксировать промпт и сравнить модели на одних контрольных примерах. Иначе влияние модели и промпта смешивается. Восемь цен — начальная проверка извлечения, не оценка всех этапов: профиль, запросы, релевантность и рекомендации требуют отдельных эталонов.

Записывать: этап, модель, промпт/хэш, корпус/хэш, параметры, finish_reason, usage, время, стоимость по тарифному снимку, ошибки схемы/цитат, ручную смысловую точность/полноту, стоимость корректного результата с повторами. Не выбирать по числу сгенерированных фактов. Нулевое число фактов не доказывает отсутствие ошибок. При отсутствии ручной разметки статус выбора — предварительный.

Практическое правило: выбрать самый дешёвый вариант среди прошедших порог качества этапа. Пороги и бюджет фиксируются до сравнения. Для критических цен и правовых условий требуется ручная проверка; модельные рекомендации не заменяют актуализацию законодательства.

## Реальный пилот 22.10.2026

Один сохранённый корпус, два контрольных фрагмента, восемь заранее размеченных цен. Это проверка работоспособности конкретной конфигурации, не универсальный рейтинг моделей.

| Модель / промпт | Контрольные цены по правилам | Принято / карантин | Ошибки | Расчёт по базовому тарифу, RUB |
|---|---:|---:|---:|---:|
| Luna / baseline_v1 | 8/8 | 158 / 7 | 0 | 2,40309 |
| Luna / evidence_v2 | 8/8 | 76 / 7 | 0 | 1,65024 |
| Gemini 3.5 Flash-Lite / evidence_v2 | 0/8 | 7 / 58 | 0 | 7,929751 |
| Claude Haiku 4.5 / evidence_v2 | 3/8 | 11 / 12 | 1 | 13,18816 |

Стоимость рассчитана из сохранённого usage и тарифного снимка; это не счёт ProxyAPI. Учтены токены обрезанного ответа Claude. Детали: runs/20261022T111451Z_0f8116/experiment_audit.json.

Gemini: 58 записей нарушили правило amount только у price, в основном модель возвращала field=service с суммой. Две цитаты дополнительно не совпали. Следовательно 0/8 не означает, что Gemini не увидела цены; текущий промпт/контракт она выполнила неудовлетворительно. Нужен отдельный адаптированный повтор, без ослабления доказательств.

Claude: первая страница завершилась finish_reason=length при 4096 токенах, весь ответ отклонён. Вторая страница завершилась stop; часть цитат перефразирована/слишком коротка. Для честного следующего сравнения явно задать поддерживаемый лимит вывода и проверить точные цитаты. Не объявлять модель неспособной на основании стандартного ограничения.

Рабочая рекомендация: Luna для текущего массового извлечения в пилоте; выбор предварительный. В evidence_v2 сохранены контрольные цены при меньшем выводе, но потеряны отдельные geography/service, а одна цитата не покрывает все детали value. Поэтому полный переход на v2 без доработки не обоснован. atomic_coverage_v3 выполнен отдельно с обновлённым валидатором; его нельзя напрямую смешивать с прежними метриками.

Для профиля и поисковых запросов выполнен пробный запуск Luna, но сравнения с альтернативами пока нет. Для рекомендаций модель ещё не оценена: итоговый выбор остаётся открытым, более дорогие Sonnet/Pro не назначены автоматически.

Дополнение: atomic_coverage_v3 завершён,8/8 цен,175 записей после проверки,3 карантин,0 ошибок. Базовая оценка2,90517 RUB. Этот вариант возвращает отдельные geography/service и исправляет наблюдавшуюся неполную цитату перечисления виз. Более высокая стоимость оправдывается проверяемым исправлением этих дефектов, но полная смысловая точность и полнота ещё не измерены; окончательного победителя нет.

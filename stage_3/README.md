## Текущий результат — 4 ноября 2026

11 согласованных конкурентов и собственная компания. 9 критериев, 30 наблюдений, 3 проверяемые гипотезы. По шести компаниям есть наблюдения; остальные явно отмечены как не исследованные в выбранном корпусе. 13 наблюдений используют реальные извлечения LLM этапа 2, ещё 17 сопоставлены исследователем с точными цитатами четырёх дополнительных страниц. Это разные способы получения данных, они не смешаны в один модельный опыт.

PortugalDom, MONOLITE и OKNO отсутствовали в сохранённых списках и добавлены пользователем. MoveToCascais уже был добавлен пользователем 21 октября; новая ссылка дополняет одну запись. Реестр происхождения — `input/user_additions.json`. Исходный этап 2 сохранён как исторический снимок.

Новые страницы загружены Python/BeautifulSoup 04.11.2026, проверены robots и сохранены очищенные тексты с SHA256. У каждого наблюдения есть источник, цитата, позиция в тексте и способ извлечения. Услуга без зафиксированной цены обозначается отдельно; она не превращается в бесплатную услугу или отсутствие предложения. 2 500 EUR PortugalDom относится к сопровождению одного человека; цена не ранжируется с пакетами другого состава. Для Испании корпус по-прежнему пуст.

## Запуск Python

```sh
python -m pip install -r stage_3/code/requirements.txt
python -B stage_3/code/analyst.py --out stage_3/results/current
python -B stage_3/code/analyst.py --country Spain --out stage_3/results/spain_no_data
python -B -m unittest discover -s stage_3/code -p 'test_*.py' -v
```

Результаты — JSON, CSV, Markdown и экранированный HTML. Конфигурация допускает подмножество компаний. Старый `results/demo` оставлен как исторический результат 27 октября; текущий — `results/current`.

Повторный сбор четырёх страниц и применение явных сопоставлений:

```sh
python -B stage_3/code/collect_additions.py --fetch
python -B stage_3/code/map_additions.py
```

Смена текста может потребовать пересмотра точных цитат. `prepare_demo.py` защищён от перезаписи текущих дополнений старым корпусом.

## SHIFT — проверка другой отрасли

Сайт https://youtube.fghk.ru/landing/?lang=en исследован отдельно от релокации. Профиль: анализ коротких видео и рекомендации по монтажу; профиль автоматически черновой. На самом лендинге видны тарифы Starter 19.99 USD/месяц за 40 видео и Growth 29.99 USD/месяц за 100; это опубликованные условия, а не проверенный платёжный сценарий.

Строгий сборщик остановился на HTTP 401 для robots.txt. Публичный лендинг просмотрен через Chrome; выбранные видимые фрагменты сохранены с явно указанным способом `cua_browser_visible_dom_selected_excerpts`. Полный HTML и работа личного кабинета не тестировались. Программе нельзя молча подменять неудачный сбор удачным.

Из веб-поиска исследователем выбраны кандидаты Retensis, Acuity и Pacing. Сохранены успешные страницы первых двух; прямой сбор Pacing не удался. Журнал фактических запросов — `cases/shift/search_log.json`. Скрипт не выполнял поисковую выдачу сам и не объявляет кандидатов подтверждёнными.

На стенде выберите SHIFT:

1. Проверьте название и описание, заполните страны, язык и аудиторию.
2. Подтвердите профиль и отметьте подходящих конкурентов.
3. Допишите свои URL при необходимости. До сбора они не попадут в сравнение.
4. Скачайте файл уточнений для Colab. Подтверждение на стенде остаётся в вашей вкладке, на сервер не отправляется.

Python принимает файл проверки только для того же проекта и SHA256 снимка. Пока профиль или конкуренты не подтверждены, результат — `needs_user_review`, содержательные рекомендации не генерируются. Синтетическое подтверждение в тестах не считается пользовательским.

```sh
python -B stage_3/code/review_case.py --case stage_3/cases/shift
python -B stage_3/code/review_case.py --case stage_3/cases/shift --review shift-user-review.json
```

## Ограничения

175 модельных фактов этапа 2 остаются черновиками. Техническая проверка цитаты не доказывает смысл, законность обещания или качество компании. Снимки имеют разные даты; полного обновления всех конкурентов нет. Состав услуг не выровнен, рейтинг цен и проценты дешевизны заблокированы. Новых LLM-вызовов не выполнялось; новый опыт выбора модели и промпта здесь не проводился. Необязательный `llm_report.py` сохранён отдельно и не включён в основной запуск.

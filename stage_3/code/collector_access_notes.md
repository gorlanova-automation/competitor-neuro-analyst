# Исправление восстановления доступа

Основной сборщик теперь импортирует resilient_fetch.fetch, а не держит отдельную упрощённую реализацию. Telegram разбирает тот же ограниченный ответ, который прошёл проверку robots, повторов и размера; прежний второй незащищённый GET удалён.

Проверка без нового сбора:

```sh
python -B -m unittest discover -s stage_3/code -p 'test_*.py' -v
```

Реальная диагностика с записью результатов и файла стенда docs/access-data.js:

```sh
python -B stage_3/code/diagnose_access.py
```

Обход всех компаний остаётся отдельным запуском market_research.py. Диагностика не перезаписывает исходный рыночный снимок и не подставляет поисковые выдержки вместо успешного HTTP-сбора.

Колабы 04–05.11 сохраняют реально выполненный комплект своей версии (20 и 25 проверок). Изменения устойчивости после этих запусков проверены локально/CI; они не выдаются за уже выполненный повторный прогон старых Colab. Новые сборки ноутбуков включат обновлённые модули, а число тестов выводится по фактически запущенному suite.

# Исправление доступа сборщика — 5 ноября 2026

Ранее один ConnectionError/таймаут скрывал причину, попытка ограничивалась первой seed-страницей, а социальные ссылки вообще не проверялись. `resilient_fetch.py` теперь используется самим market_research.py и через него promotion_research.py.

- Раздельные статусы: DNS, соединение, таймаут, TLS, прокси, HTTP, 429, размер/формат, недоступный robots, запрет robots, неверный HTML вместо robots, login, challenge и страница для отрисовки.
- До двух попыток при временном сбое/5xx; короткий Retry-After учитывается, долгий переносит запрос на потом. DNS/TLS/прокси не повторяются слепо.
- Лимит проверяется во время потокового чтения, а не после скачивания всего ответа. TLS-проверка включена.
- Обход использует все подтверждённые seed-URL, не только первый. Неуспешная страница не исчерпывает весь лимит успешных страниц; общий потолок попыток — max_pages × 3.
- При DNS для www проверяется тот же домен без www; другой бренд/домен не подбирается автоматически. В диагностике Релокейт Групп добавлены официальные страницы /o-nas/ и /o-nas/kontakti/, предварительно подтверждённые веб-поиском. Поиск не объявляется выполненным скриптом.
- Журнал каждой попытки, результат проверки robots и признак повторного использования robots-кэша, следующий шаг и очередь ручной проверки сохраняются отдельно. Неудачи не затирают старые успешные снимки исследования.

## Реальная проверка

`python stage_3/code/diagnose_access.py` действительно повторно проверяет два проблемных сайта и обнаруженные Instagram/Facebook-ссылки; собственный сайт используется как положительный контроль. `summary.json` содержит текущие результаты, отдельные файлы — попытки и причины.

Первый новый прогон: контрольный сайт получен. Для обоих вариантов Migran — DNS; для robots Релокейт Групп — таймаут после двух попыток. Ссылки Instagram/Facebook теперь действительно проверены, а не просто перечислены: для исследованных адресов robots запрещает этот сбор. Это не доказательство закрытого профиля и не отсутствие публикаций. Контент не скачивался в обход запрета.

Страница входа/защиты/короткая JS-оболочка не считается успешным чтением. Очередь browser_review_queue — запрос следующего действия, не заявление об уже выполненном просмотре браузером. Выполнение в Chrome требует разрешённого инструмента cua_repl; скрипт не управляет Chrome скрытно и не меняет настройки сети/сертификатов. Получить данные с любого сайта независимо от DNS, правил или авторизации невозможно.

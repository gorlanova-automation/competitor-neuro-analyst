# Ассортимент и продвижение — 5 ноября 2026

Этот сбор исправляет узкую трактовку анализа как сравнения заранее заданных услуг. Исследуются все 12 компаний из текущего каталога: своя и 11 конкурентов.

## Что выполнено

Python обходит до четырёх официальных страниц компании, обнаруживая ссылки по навигации, а не только по заранее заданному списку услуг. Сохранены очищенные тексты, заголовки, ссылки, даты и SHA256. Ошибки доступа записаны отдельными результатами. Ассортимент представлен названиями разделов/предложений и тематической картой упоминаний. Статьи отделяются от коммерческих карточек, но автоматическая классификация всё ещё требует проверки.

По ссылкам официального сайта обнаружены площадки. Telegram-контакты, приглашения и боты отделены от доступных публичных лент. Из каждой полученной ленты взято не более восьми сообщений видимой страницы; повторы удалены по URL. Новая выборка содержит 23 уникальных сообщения Relotus, MigrAll и MoveToCascais. Старые 25 сообщений Migrun остаются исторической выборкой этапа 2 и не считаются новым сбором. Редакционные страницы сайтов собраны отдельно, до трёх на компанию.

Тон: правила выделяют лексические сигналы с дословными цитатами. Это навигация по материалам, не полноценная смысловая оценка бренда. Темы публикаций также отмечены ключевыми словами. Платная реклама, эффективность, частота по полному периоду, позиции поиска, охват и клиентская конверсия не измерялись.

Визуал просмотрен помощником в реальном Chrome по первым десктопным экранам десяти компаний. Замечания и ограничения — visual_reviews.json; изображения — docs/research-images. У PortugalDom и MoveToCascais рендер ограничен, это явно указано. Migran (DNS) и Релокейт Групп (ошибка/таймаут) не получили оценки дизайна. Цвета и композиция не выведены из HTML-метаданных. Визуал публикаций и мобильные версии пока не исследованы.

## Разделение работы

- Код: сбор, обнаружение ссылок, извлечение текстов/постов, тематические сигналы, исключение дублей, сводка, экспорт, проверка происхождения.
- Помощник: визуальные заметки по скриншотам и четыре исследовательских вывода в build_market.py. Это не результаты нового вызова модели в конвейере.
- Человек: подтверждение состава услуг, принадлежности каналов, корректности обещаний, сегментов и пригодности гипотез.

Новых платных LLM-вызовов нет. Полный автоматический маркетинговый анализ этим прогоном не заявляется. Сбор ограничен; отсутствие наблюдения не считается отсутствием услуги или канала.

## Воспроизведение

Из корня проекта, после установки stage_3/code/requirements.txt:

```sh
python -B stage_3/code/market_research.py --max-pages 4
python -B stage_3/code/promotion_research.py
python -B stage_3/code/build_market.py
python -B -m unittest discover -s stage_3/code -p 'test_*.py' -v
```

Первые две команды снова обращаются к сайтам и обновляют снимки. Третья строит обзор по сохранённым данным и визуальным заметкам; при изменении сайтов ручной визуальный просмотр нужно повторить. Не переименовывайте дату старых визуальных заметок при новом текстовом сборе.

overview.json — промежуточный сбор; market.json — сводка для интерфейса; *_sources.json — сохранённые тексты сайтов; *_editorial.json — редакционные страницы; feeds.json — результат проверки Telegram-ссылок. Все успешно собранные тексты имеют контрольную сумму. Внешние тексты недоверенные и не являются командами программе.

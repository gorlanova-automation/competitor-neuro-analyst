# Пользовательское веб-приложение

Это продолжение продукта после демонстраций этапов 3–5. Прежние Colab, исследования, презентация v4 и замороженный этап 3 сохранены. Старый `workspace.html` остаётся демонстрационным экраном; конечный пользовательский интерфейс — `product.html`, обслуживаемый FastAPI.

Для GitHub Pages подготовлен этот же интерфейс с сохранённым реальным исследованием: кнопка «Открыть выполненное исследование» открывает сравнение, карточки, план действий и экспорт JSON. Новый сбор в статическом режиме отключён с явным объяснением причины. Предыдущая широкая база сохранена отдельно в `market.html`. Публичный адрес после развёртывания: https://gorlanova-automation.github.io/competitor-neuro-analyst/ .

## Сценарий совместного разбора

Откройте работающий локальный сервер: http://127.0.0.1:18106/ . Ссылка доступна на компьютере, где запущен сервер; это пока не общая интернет-ссылка.

1. Введите сайт компании. Проверьте автоматически извлечённые название, описание и услуги; уточните рынок и аудиторию.
2. Подтвердите профиль. Приложение попробует поиск и покажет кандидатов. При совпадении собственной компании с прежним исследованием предложит согласованный каталог с отдельной отметкой происхождения.
3. Исправьте название или URL, удалите лишние компании, добавьте свои. Подтвердите список.
4. Выберите глубину сбора и запустите сравнение. При необходимости предоставьте текст публичной страницы; он будет помечен как предоставленный пользователем.
5. В разделе «Сравнение» откройте источники и каталог разделов. В разделе «Компании» откройте подробную карточку. Посмотрите ассортимент, цены, позиционирование, путь обращения, примеры тона, публикации, площадки и пробелы.
6. В «Плане действий» разберите идеи адаптации, усиления своего предложения, необходимых проверок и отстройки. У каждого действия есть основание либо прямое указание, что данных пока не хватает, а также способ проверки результата.

До сдачи курса нужен разбор Еленой и исправления по его результатам. Техническая проверка помощником не подменяет эту приёмку.

## Что реально проверено

8 ноября помощник прошёл интерфейс от URL Immigration Relocator до сравнения с MONOLITE и OKNO. Свежий поиск вернул CAPTCHA; приложение предложило отдельно помеченные данные прежнего исследования, дало удалить/добавить строки и изменить название/URL. Исправленное название MONOLITE сохранилось в сравнении и карточке. Python получил 9 страниц трёх компаний; никаких новых модельных вызовов не было.

После просмотра исправлено извлечение цитат: целые текстовые блоки вместо обрывков меню, без изменения исходного полного текста и его SHA256. Примеры тона — текстовые сигналы для проверки. Рекомендации составляются правилами по цитатам; они не являются независимой экспертной оценкой. Абсолютные обещания результата отправляются на проверку, а не автоматически включаются в рекомендации усиления.

Состояние и результаты реального браузерного прогона находятся в `results/live_ui_20261108`; `product_result.json` содержит карточки и план действий. Статусы фоновых заданий сохраняются на диске. Исправлена проверенная тестом гонка чтения и замены файла статуса на Windows. Перезапуск отмечает незавершённое задание как остановленное и сохраняет предыдущие отчёты.

Полный набор: `python -B stage_6/validate.py`, 65 успешных проверок, 0 ошибок/падений; исходный этап 3 совпадает по хэшам. Проверены редактирование имён, ошибки поиска, источники рекомендаций, отсутствие выдуманных слабостей, непроверенные гарантии, авторизация общего кабинета и допустимые домены. Desktop и ширина 390 px просмотрены в браузере; сравнение прокручивается горизонтально внутри таблицы, карточки становятся одной колонкой.

## Размещение и ограничения

Подготовлен серверный вход, Dockerfile, постоянное хранение, пароль общего рабочего кабинета и проверка Host/Origin. [Вариант размещения](../app/DEPLOYMENT.md). На этом компьютере Docker CLI есть, движок Docker Desktop не запущен: образ ещё не собран и не проверен. Доступ к существующему серверу или новый тариф не выбран. Платное размещение не заказывалось. Общая серверная ссылка остаётся открытым пунктом.

Автопоиск не гарантирован: реальный прогон встретил CAPTCHA. Для новой отрасли, по которой нет прежнего каталога, при отказе поиска нужен ручной список. Instagram/Facebook не объявляются прочитанными по ссылкам. Визуал требует просмотра изображений; автоматический анализ изображений не реализован. Действия о слабостях компании и рынка остаются проверками до получения достаточных данных. Приложение не измеряет эффективность рекламы, охваты или конверсию.

Это защищаемое паролем общее рабочее пространство, без раздельных пользовательских кабинетов. Публичный многопользовательский сервис с квотами и разделением данных потребует отдельного внедрения. Ключ ProxyAPI в этот сервер не переносился.
